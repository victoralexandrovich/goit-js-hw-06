# GoIT JS Homework 06 - Prototypes, Classes & Private Properties
JavaScript homework assignment for the GoIT course (Module 6). Topic: object context (`this`), ES6 classes, constructor functions, methods, and private class properties (`#`).

**What was done:**
- Set up the repository `goit-js-hw-06` and configured the project structure according to the course requirements
- **Task 1 (User Account):** Refactored the `customer` object methods by properly adding the `this` keyword to access and modify object properties (`balance`, `discount`, `orders`)
- **Task 2 (Storage):** Created the `Storage` class with a private property `#items` and public methods (`getItems`, `addItem`, `removeItem`) to manage inventory items securely
- **Task 3 (String Builder):** Created the `StringBuilder` class with a private property `#value` and methods (`getValue`, `padEnd`, `padStart`, `padBoth`) to manipulate strings dynamically
- Verified code formatting with Prettier and ensured zero errors or warnings in the browser console across all tasks via GitHub Pages
